# Bazaar Markets v1.0.0: frozen rule-based baseline

**BLUF.** Engine 1.0.0 freezes the rule-based market simulator and every result produced with it so far. It is the baseline that later agents (LLM or otherwise) will be compared against on paired seeds. Every finding is listed, with its run, estimate, interval and status, in [`runs/BASELINE_1_0_0.md`](https://github.com/RandallSPQR/Bazaar-Markets/blob/v1.0.0/runs/BASELINE_1_0_0.md) (96 rows: 29 confirmatory and supported, 3 contradicted, 3 not supported, 1 partly supported, 35 exploratory, 19 provisional, 6 superseded). The full test suite passes at this commit (1,817 passed, 17 skipped).

## What it is

A deterministic simulator of a bazaar: stalls selling fish, electronics and designer goods. Stalls are genuine, seconds (honestly labelled lower quality) or deceptive. They advertise by sign, yell and whisper. Buyers (tourists, locals, experts, bargain hunters) compare stalls, read star ratings and sometimes inspect before buying. Inspectors patrol, stand on posts or work disguised. Brands can be built, licensed, copied or cashed in. Agents act only at decision points, so any agent can be dropped into the same market and compared seed for seed.

## Headline results (rule-based agents; one stylized model, not claims about real markets)

- **Verification bounds cashing in a brand.** With no inspectors, a stall that switches to cheap goods under its good name gains when no buyer checks, and loses once enough buyers do (confirmatory). The crossing near a third of buyers is an interpolation without an interval. Stage 1 (checking vs reading ratings) shows the boundary is set by buyers inspecting, not by buyers reading ratings (rows K1–K2).
- **Enforcement substitutes for verification** (confirmatory). Honest sellers' profit rises with enforcement (exploratory; the mechanism is not decomposed).
- **Enforcement leaks through gaps in space and time.** Fixed inspectors leave pockets, and visible patrols can be waited out (the latter is an upper bound from a perfect-avoidance seller).
- **Catch counts mislead.** Sellers who dodge inspectors earn more only by paying fewer fines.
- **A reputation is worth the head start it gives over rivals still building theirs:** about $190 for each day of head start where buyers read ratings, and nothing once rivals show the same stars. With tourists only, slow rivals gain instead. Stage 1 shows this effect depends on buyers reading ratings, and shrinks where they inspect (rows K3–K4).

Each headline's exact wording, its source rows and how far the evidence supports it are in section 3.6 of the baseline manifest.

## What is in this release

- `engine/`: market engine 1.0.0 (deterministic per seed). One fix over 0.21.0: a counterfeit of a white label's name follows the white label's price (found by the formal-model cross-check, item C1; no published run reaches it).
- `configs/reference_1_0.json`: the reference market. `configs/reference_1_0_variants.json` turns it into the market of each published run since verification.
- `tests/reference/v1_0_0/`: regression digests of 576 chains from every published run since engine 0.14.0, each matching its saved run record field for field. `BAZAAR_FULL_REGRESSION=1 pytest tests/test_reference_1_0.py` checks all of them (about 1.5 h on 4 workers). The default run checks one chain per run.
- `docs/formal_model.md` and `runs/formal_model_check.md`: the formal model, cross-checked against the code.
- `docs/agent_interface.md`: every decision point, what an agent sees and may return, and the deliberate rules of this world.
- `runs/`: one summary per run, with run record, gates, predictions table, a reading written after the results, and caveats; plans and preregistrations; the baseline manifest.
- `analysis/`: one script per run. Chains are paired by seed; intervals are 95% t over seeds, unadjusted.
- `viewer/`: a browser viewer for engine logs.

## Data

Run caches (every chain behind every summary; 32 files, about 800 MB uncompressed) are not in git. They are archived on Zenodo as `bazaar-markets-v1.0.0-run-caches.tar.gz`, with SHA-256 checksums of each file inside the archive. Each cache can also be regenerated from its script and seeds.

## Reproducing

    pip install -e ".[test]"
    pytest                                                     # about 1.5 h
    python -m cli.run --config configs/reference_1_0.json --seed 0

Python 3.12, numpy 2.5. Each run summary gives its command, engine, commit and seeds.

## Known limitations and open questions

- Agents are rule-based. Nothing here tests how an LLM agent behaves; that comparison comes next, against this baseline.
- Walk-mode brand, counterfeit, dilemma-boundary and capture runs are provisional: in walk-mode demand buyers stop at the first acceptable stall, so most stalls are rarely reached (the choice-set market used from verification on replaces it). The verification Stage B run at 0.13.0 and the exact-rating Brand Equity speed run are superseded.
- Open questions on labels and wording are listed in section 6 of the baseline manifest (for example, how the README should label the reputation headline, and whether rows R10–R12 should also be marked superseded).
